# 验收证据入口

- `cases/matrix.json`：十二案例结果及固定提交；TC-05、TC-10 勘误见 docs。
- `fixtures/*.bundle`：七个可离线克隆的 Git 包。
- `model/`：重启前后真实模型调用摘录，source_sha256 对应私有原始记录；原始记录未随包发布。
- `server/`：服务器部署及重启验收历史记录。
- `report/`：真实 Finding 导出的报告。
- `PUBLICATION-CHECK.json`：本次本地发布检查结果。
- `SHA256SUMS`：本目录其他文件的 SHA-256；校验清单自身不包含在内。

本次只进行交付完整性、离线恢复、固定提交可用性及常见密钥模式检查；未重新运行服务器或付费模型验收。历史证据的哈希只能验证文件完整性，不能独立证明其全部外部执行过程。
