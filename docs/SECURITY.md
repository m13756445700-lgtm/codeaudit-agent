# 安全边界

本系统面向一个可信操作员。agent-compose daemon 挂载 Docker socket，具备主机管理能力；不开放公网 daemon/MCP，不当作多租户隔离平台。worker 仅在 internal 网络接收固定能力调用，不能向其额外挂公共网络。目标仓库只作为不可信数据，不执行目标代码、构建、依赖安装或漏洞利用。

Git/ZIP/local 输入经过UUID快照、文件/字节/时间上限、路径与链接检查。工具受允许列表和范围限制；shell不是模型公开工具。词法导航和固定Semgrep规则覆盖有限；模型也可能被误导或产生错误语义判断，因此重要发现需人工复核。

模型服务收到被选中的源码片段和判断知识。操作员必须选择适合代码保密要求的模型endpoint。TLS验证开启；只有显式loopback本地模型允许HTTP。模型私有推理字段不落盘；可审计的是计划、动作、证据和判断。

`.env`、`.runtime.env` 权限0600，不进入Git/Docker build context；token随机生成。私钥不能存放项目目录，私有Git仅显式挂载。报告、trace和源码快照都是敏感数据，保存在专用卷及操作员导出目录；不要公开原始证据或完整compose环境输出。

Gate核对真实读取、行号和哈希，不证明漏洞因果绝对正确。COMPLETE不是全库安全认证，需展示未读文件、Unknown和限制。缺失模型/MCP/预算时不伪造成功。基准夹具含刻意脆弱代码，仅用于受控测试，不提供可公开部署的靶场服务。
