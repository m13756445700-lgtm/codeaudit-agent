# 调查状态与收尾整改

依据第七轮真实轨迹：模型直到预算末尾才提交判断，部分判断引用未登记假设。现有状态仅在上下文压缩或工具回执中出现，最后六轮提醒不足以完成引用修正与攻击面结算。

方案：每次模型调用前提供替换式、精简的权威状态快照，列出已登记假设、已通过决策、待修正Gate、原始计划攻击面和剩余预算；预算后三分之一提示优先结算。所有工具仍可选择，模型继续决定假设、安全判断及延期范围。缺失假设错误明确指出准确编号与修复操作。finish工具说明区分“读取证实不存在”和“尚未审查”。

不采用仅扩大预算，也不采用自动创建假设、自动改PARTIAL或替模型填写判断。保持原有Gate和完成契约。快照不能引入未读证据，旧快照必须移除以免增加上下文。

验证：状态在多轮及压缩后准确；已通过决策不被误列待办；缺失假设仍拒绝；早期收尾提示不自动结束运行。Linux全回归后冻结版本，串行运行与第七轮相同四例，另对go-shell重复三次。已知案例仅算回归，不作为独立泛化成绩。
