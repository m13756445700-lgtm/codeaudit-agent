# Command 跨方法首批实施边界

沿用已确认的BRD及TC-05勘误。复用现有Gate和五个受控方法。

1. 先重验真实Codex/DeepSeek会话，仍要求逐候选工具覆盖、零工具失败、最终结果与可信记录完全一致。
2. 支持显式、唯一类型解析的public static方法链，最多6层；Controller请求参数只能直传，不接受动态分派或未经证明的参数变换。
3. 数据流记录每次调用实参和被调方法形参，任何测试路径不得判为生产可达。
4. 重载、同名歧义、断链、未知过滤、重赋值、递归无来源均保留NEEDS_REVIEW。
5. 专项测试后运行全量回归。容器与模型结果必须标注对应版本，不能将旧镜像验证冒充新代码验收。

不在本批承诺：任意Java跨过程分析、实例注入解析、SSRF、Path Traversal。
